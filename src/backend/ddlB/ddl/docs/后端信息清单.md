## 1. 实体类字段定义

### 1.1 通用约定

- **主键**：五个实体主键均为 **`String uuid`**，注解 `@TableId(type = IdType.ASSIGN_UUID)`，与全局 `id-type: assign_uuid` 一致。
- **时间字段**：业务实体中的 **`createdAt` 均为 `String`**（非 `LocalDateTime`）。`User` 无时间字段。
- **四象限 / 优先级**：实体中**无** `level` 字段。待办使用 **`priority`（`Integer`）**；后端**未**定义 Java 枚举与象限映射，注释仅说明列表排序与「四象限」相关。**数值与象限的对应关系由前端约定**。
- **正文字段**：待办正文为 **`content`**，不是 `description`。

### 1.2 User.java → 表 `user`

|------|------|------|

## 2. 统一返回格式 `Result.java`

- 类名：`common.Result<T>`（泛型）。
- **code**：`200` 表示成功；`Result.error(String msg)` 时为 **`500`**；亦支持 `error(Integer code, String msg)`。
- **msg**：提示信息。
- **data**：业务数据；仅消息无载荷时可为 `null`。

常用静态方法：

- `success()` / `success(T data)` / `success(String msg, T data)`
- `error(String msg)` / `error(Integer code, String msg)`

## 3. Controller 接口一览

**说明**：当前为「按 `userId` 全量备份 / 拉取」为主，**不是** REST 单资源 `/add`、`/update/{id}`、`/delete/{id}`、`/get/{id}` 全套（除 Note 的 `save` 为单条 upsert）。

### 3.1 UserController — `/api/user`

| 方法 | 路径 | 请求 | 响应 data |
|------|------|------|-----------|
| POST | `/api/user/login/mock` | Body：`LoginDTO` | `User` |
| POST | `/api/user/update` | Body：`User` | 无（`success("更新成功")`） |

### 3.2 TodoController — `/api/todo`

| 方法 | 路径 | 请求 | 响应 data |
|------|------|------|-----------|
| GET | `/api/todo/list` | Query：`userId` | `List<TodoTask>` |
| POST | `/api/todo/backup` | Query：`userId`；Body：`List<TodoTask>` | 无（成功仅 msg） |

### 3.3 TargetController — `/api/target`

| 方法 | 路径 | 请求 | 响应 data |
|------|------|------|-----------|
| GET | `/api/target/restore` | Query：`userId` | `List<Target>` |
| POST | `/api/target/backup` | Query：`userId`；Body：`List<Target>` | 无 |

### 3.4 PlanController — `/api/plan`

| 方法 | 路径 | 请求 | 响应 data |
|------|------|------|-----------|
| GET | `/api/plan/restore` | Query：`userId` | `List<Plan>` |
| POST | `/api/plan/backup` | Query：`userId`；Body：`List<Plan>` | 无 |

### 3.5 NoteController — `/api/note`

| 方法 | 路径 | 请求 | 响应 data |
|------|------|------|-----------|
| GET | `/api/note/restore` | Query：`userId` | `List<Note>` |
| POST | `/api/note/backup` | Query：`userId`；Body：`List<Note>` | 无（成功仅 msg） |
| POST | `/api/note/save` | Body：单个 `Note` | `Note` |

## 5. 后端基础配置

| 配置项 | 值 |
|--------|-----|
| 默认端口 | **8080**（`src/main/resources/application.yml`） |
| 根地址示例 | `http://localhost:8080` |
| API 前缀 | `/api/user`、`/api/todo`、`/api/target`、`/api/plan`、`/api/note` |
| 数据源 | MySQL，库名示例：`ddl_db`（见 `application.yml`） |
| MyBatis-Plus | 驼峰映射；全局主键 `assign_uuid` |

### 5.1 跨域（CORS）

- 配置类：`config.WebMvcConfig`
- 映射：`/**`；方法含 GET、POST、PUT、DELETE、OPTIONS；`allowedOriginPatterns("*")`；`allowCredentials(true)`。

**注意**：启动类 `com.ddl.DdlMasterApplication` 默认只扫描 **`com.ddl`** 包。若未设置 `scanBasePackages` 包含 `config`、`common`，则 **`WebMvcConfig` / `GlobalExceptionHandler` / `Result` 所在包可能未被加载**，跨域与统一异常可能不生效。若遇跨域不生效，请检查组件扫描范围。

## 6. 与「单条 CRUD 接口清单」的对照

| 常见期望 | 当前实现 |
|----------|----------|
| `/add`、`/update/{id}`、`/delete/{id}`、`/get/{id}` | **未提供**（Todo/Target/Plan） |
