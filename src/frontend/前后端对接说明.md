## 📊 前后端字段映射关系

### Todo / TodoTask 映射
| 前端 (Todo) | 后端 (TodoTask) | 映射方式 |
|------------|----------------|---------|
| `id` | `uuid` | 直接映射 |
| `desc` | `content` | **字段名转换** |
| `completed` (boolean) | `status` (0/1) | **类型转换** |
| `level` (四象限) | `priority` (1-4) | **枚举映射** ⬇️ |
| `createdAt` | `createdAt` | 直接映射 |
| `planId`, `targetId` | `planId`, `targetId` | 直接映射 |
| **前端独有** ⬇️ | - | 保存在 localStorage |
| `beginTime`, `endTime` | - | 不同步后端 |
| `category` | - | 不同步后端 |
| `isContinuous` | - | 不同步后端 |
| `summury` | - | 不同步后端 |

#### 四象限优先级映射
```typescript
'urgent-important'         → priority = 4
'urgent-not-important'     → priority = 3
'not-urgent-important'     → priority = 2
'not-urgent-not-important' → priority = 1
```

### Target 映射
| 前端 | 后端 | 说明 |
|------|------|------|
| `desc` | `content` | 字段名转换 |
| `completed` (boolean) | `progress` (0/100) | completed=true → progress=100 |
| `beginTime`, `endTime`, `weight` | - | 仅存 localStorage |

### Plan 映射
| 前端 | 后端 | 说明 |
|------|------|------|
| `desc` | `content` | 字段名转换 |
| `completed` (boolean) | `progress` (0/100) | completed=true → progress=100 |
| `beginTime`, `endTime`, `weight`, `isRepeat` | - | 仅存 localStorage |

### Note 映射
| 前端 | 后端 | 说明 |
|------|------|------|
| `updatedAt` | - | 后端无此字段，使用 `createdAt` 代替 |

## 🔄 数据同步策略

### 混合模式：localStorage + 后端备份

#### 数据流向
```
用户操作 → 立即保存到 localStorage（保证响应速度）
         ↓
    自动调用后端 API 备份（异步，失败不影响本地）
```

#### 启动流程
```
1. 应用启动
2. 各 hook useEffect 触发
3. 调用 /list 或 /restore 从后端拉取数据
4. 成功：覆盖 localStorage
5. 失败：继续使用本地数据（后端可能未启动）
```

#### 操作流程（以 addTodo 为例）
```typescript
1. 创建新 Todo（包含 UUID）
2. 更新 localStorage（同步操作）
3. 调用 todoApi.backup() 备份到后端（异步）
4. 失败也不影响，数据已保存到本地
```

## ⚠️ 注意事项

### 1. 后端字段差异
- ✅ 已通过 `typeMapper.ts` 自动处理
- 前端独有字段（beginTime, category等）**不会**同步到后端
- 这些字段会继续保存在 localStorage 中

### 2. ID 生成方式变更
- **之前**：`Date.now().toString()` （时间戳）
- **现在**：`crypto.randomUUID()` （UUID）
- **原因**：与后端 `assign_uuid` 策略一致

### 3. 异步操作
- 所有 CRUD 方法现在都是 `async`
- 调用时需要 `await` 或处理 Promise
- 示例：
  ```typescript
  // ❌ 旧代码
  addTodo({ title: '测试' });
  
  // ✅ 新代码
  await addTodo({ title: '测试' });
  ```

### 4. 错误处理
- 网络错误会在控制台显示，但不会阻止应用运行
- 数据始终保存在 localStorage，即使后端挂了也能用
- 后端恢复后，下次操作会自动同步

### 5. 用户 ID
- 当前固定使用 `MOCK_USER_ID = 'mock-user'`
- 后续添加登录功能后，需要修改 `typeMapper.ts` 中的逻辑

## ❓ 常见问题

### Q1: 点击保存后没有反应？
检查：
1. 浏览器控制台有没有报错
2. Network 标签有没有请求
3. 后端服务是否启动

### Q2: 数据保存到本地了，但后端没有？
检查：
1. 控制台是否有 `同步失败` 的日志
2. 后端跨域配置是否正确
3. 后端 API 路径是否正确

### Q3: 刷新页面后数据丢失？
检查：
1. localStorage 中是否有数据（Application → Local Storage）
2. 后端是否返回了数据
3. 控制台是否有同步错误

### Q4: 字段对不上？
查看 `typeMapper.ts` 中的映射逻辑，确认字段名转换是否正确。
